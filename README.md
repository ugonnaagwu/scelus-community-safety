# Scelus — Community Safety Demo

**Safe Today. Secure Tomorrow.**

Scelus is a portfolio demonstration of a community safety platform originally developed during the Girls Who Code Leadership Academy.

## Demo
This version is intentionally self-contained: no Node, npm, VS Code, backend, or build step is required.

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Features
- Mobile-first Scelus interface
- Supplied Scelus logo and branding
- Safety alerts with search and filters
- Missing-person workflow
- Safety map prototype
- Emergency and crisis support
- Community resources
- Safety tips
- Incident-report modal
- Responsive desktop layout

## Data disclaimer
The safety alerts and missing-person records are **sample/demo data**. They are not official public-safety records. A production application should connect only authorized, verified sources and use appropriate privacy, moderation, security, and retention controls.
